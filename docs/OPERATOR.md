# Operator

1. Settings → paste the operator-room path segment (never stored in source).
2. Operator tab → identity + passphrase.
3. Mortis returns a session. Idle 15m / absolute 60m.

## Release

Dataset publish is not a player binary. Withheld payloads stay withheld.
